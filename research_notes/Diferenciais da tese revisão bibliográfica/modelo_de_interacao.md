# Interaction model: hidden symbolic state c + observable low-level state x, operators triggered by low-level "events"

Thesis model recap (for the report writer): state = (c, x); c = hidden complete STRIPS theory; x = fully observable low-level state; agent acts only via low-level actions a (DQN/HER); every change of c is a no-op or the application of a domain operator of D_Γ ("consistency"); events e = (x_e, a_e, x'_e, ω_e) are known a priori and trigger operator ω_e; observation ψ = Φ(c, x) ⊆ c, partial and truthful (three-valued); environments sampled from hyperparameters θ but share D_Γ; abstract BFS over (x, Π) using events, inner BFS over replay buffer H to reach an event while avoiding other events, random exploration otherwise; goals arrive in sequence, knowledge persists.

Verification legend: **[verified]** = existence/venue/claims confirmed in this session from a primary or bibliographic page; **[from memory - unverified]** = citation recalled but URL/details not checked in this session.

## 1. Belief-space TAMP and hierarchical POMDP planning with symbolic abstractions

### Takeaway
Belief-space TAMP (BHPN) is the classical framework that also mixes a hidden/uncertain discrete state with continuous geometry and plans over beliefs, but it assumes known models for both levels (including observation and motion models) and does not learn low-level behaviour by RL. Overlap with the thesis is **partial**: shared "plan at symbolic level over partial knowledge, refine to low level" idea; distinct in that the thesis' low-level dynamics are unknown, the abstract-low coupling is through a priori known events, and low-level paths come from a replay buffer rather than a motion planner.

### Inferences
- In BHPN/TAMP, the symbolic state is typically a *deterministic function* (or belief summary) of the geometric/world state, and operators are *chosen* by the planner and refined by samplers/motion planners. In the thesis, c is not a function of x (it is hidden, independent information), and operators are *triggered* by low-level transitions (events) rather than being executable primitives — the agent can only reach an event's precondition (x_e) and execute a_e.
- BHPN's belief is a probability distribution; the thesis uses a three-valued (known-true / known-false / unknown) truthful partial observation — closer to contingent/conformant classical planning with sensing than to POMDP belief.
- Verdict: **partial overlap** (two-level, partial observability, interleaved planning/acting); **distinctive** for the thesis: unknown low-level dynamics learned by RL, event-triggered abstract transitions, replay-buffer path search, procedurally generated environment families sharing D_Γ, and sequential goals with persistent knowledge.

## 2. Options / skills linked to symbolic operators (Konidaris; Silver et al.; Illanes; IBM PaRL & POHRL; RePReL; SDRL; PEORL)

### Takeaway
The closest formal match is IBM's PaRL ("Hierarchical RL with AI Planning Models", Lee et al.): it requires that every MDP transition maps either to no abstract change or to an abstract planning transition — essentially the thesis' "consistency" condition — but PaRL's abstraction L is a surjective function of the (observed) MDP state, so the symbolic state is observable, whereas in the thesis c is hidden and only partially revealed by Φ. The IBM follow-up "Partially Observable HRL with AI Planning" (AAAI 2024 student abstract) is the closest on partial observability (unknown predicates with known possible valuations; plan splits the POMDP into a tree of semi-POMDPs) but, from the abstract, still learns one option per operator rather than using known events plus replay-buffer search. Overlap: **partial (high)** with PaRL/POHRL; **partial/superficial** with the others.

## 3. Reward machines and labelling functions (including noisy / partial labelling)

### Takeaway
Reward machines (RMs) are the closest match to the *event* mechanism: an RM transition is triggered by the labelling function evaluated on a low-level transition (s, a, s'), exactly like an event triggers ω_e. But the RM state encodes task progress/memory, not a world theory with STRIPS preconditions/effects shared across tasks; noisy-labelling RM work (Li et al. NeurIPS 2024, Verginis et al. 2022) is closest to the thesis' hidden symbolic layer. Overlap: **partial** (mechanism similar, semantics different).

### Cited Findings
- Toro Icarte, Waldie, Klassen, Valenzano, Castro, McIlraith. "Learning Reward Machines for Partially Observable Reinforcement Learning." NeurIPS 2019, pp. 15523–15534 **[verified]** — [NeurIPS proceedings](https://proceedings.neurips.cc/paper/2019/hash/532435c44bec236b471a47a88d63513d-Abstract.html). RMs learned from experience via discrete optimisation so that subproblems admit memoryless policies; RM state acts as external memory in POMDPs; beats A3C, PPO, ACER on three partially observable domains — same source; code on Bitbucket per [author PDF](https://www.cs.toronto.edu/~rntoro/docs/LRM_paper.pdf).
- Toro Icarte, Klassen, Valenzano, McIlraith. "Reward Machines: Exploiting Reward Function Structure in RL." JAIR 73, 2022; arXiv:2010.03950 — [arXiv](https://arxiv.org/abs/2010.03950) **[from memory - unverified]**; original ICML 2018 paper "Using Reward Machines for High-Level Task Specification and Decomposition in RL" **[from memory - unverified]**. In the RM formalism the labelling function L: S × A × S → 2^P assigns propositions to transitions **[from memory - unverified]**.
- Li, Chen, Klassen, Vaezipoor, Toro Icarte, McIlraith. "Reward Machines for Deep RL in Noisy and Uncertain Environments." NeurIPS 2024; arXiv:2406.00120 **[verified]** — [arXiv](https://arxiv.org/abs/2406.00120v3); [NeurIPS poster](https://neurips.cc/virtual/2024/poster/96134). Standard RMs assume ground-truth interpretation of propositions, which is elusive under partial observability and noisy sensing; they cast the problem as a POMDP and propose RL algorithms exploiting RM structure without an oracle labelling function; expose pitfalls of naive approaches — [arXiv html v4](https://arxiv.org/html/2406.00120v4).
- Verginis, Koprulu, Chinchali, Topcu. "Joint Learning of Reward Machines and Policies in Environments with Partially Known Semantics." arXiv:2204.11833 (2022) **[verified existence; venue not confirmed]** — [arXiv](https://arxiv.org/abs/2204.11833). Maintains probabilistic estimates of atomic propositions updated by sensor measurements, plus a hypothesis RM; Q-learning over hypothesis RM; proves recovery of the RM and asymptotic task completion — same source.
- Parać, Nodari, Ardon, Furelos-Blanco, Cerutti, Russo. "Learning Robust Reward Machines from Noisy Labels" (PROB-IRM), KR 2024 **[verified existence]** — [KR proceedings PDF](https://proceedings.kr.org/2024/85/kr2024-0085-parac-et-al.pdf).
- ARM-FM: "Automated Reward Machines via Foundation Models for Compositional RL" (arXiv 2510.14176) appeared in search, uses XLand-MiniGrid-like settings **[existence only]** — [arXiv](https://arxiv.org/abs/2510.14176).

### Inferences
- **Event ≈ labelled transition.** The thesis' event (x_e, a_e, x'_e, ω_e) is equivalent to a labelling function that fires a single proposition "ω_e happened" on one specific low-level transition. The difference is what the label drives: in RMs it advances a task automaton (the reward structure); in the thesis it applies a STRIPS operator to a hidden world theory c, whose preconditions may be unknown to the agent (so an event may fire with unknown effect/applicability until observed). The thesis' c is environment state shared across goals; RM state is per-task.
- Li et al. 2024 is the closest RM work to "hidden symbolic state": propositions are not directly observed, and the agent must reason under uncertainty about them. But the uncertainty is in the *labelling* (noisy sensing), not in a hidden STRIPS state evolving by operators; and the thesis' observation is truthful (no noise), three-valued.
- Verdict: **partial overlap** (mechanism of transition-triggered abstract updates is shared; semantics — world model vs task automaton — differ). Distinctive: STRIPS consistency, truthful partial observation, planning (BFS) rather than RL over RM product states, transfer across θ-generated environments and goal sequences.

## 4. Planning on graphs built from replay buffers / landmarks (SoRB, world graphs, SGM) vs inner BFS over H

### Takeaway
SoRB and successors build a graph whose nodes are replay-buffer states and whose edges are weighted by a learned goal-conditioned distance, then run shortest-path search to produce waypoints for a goal-conditioned policy. The thesis' inner BFS over H is the same idea in a deterministic/discrete setting with *exact observed transitions* as edges and with an additional constraint (avoid triggering non-target events). Overlap: **partial (methodological)**; the coupling to an abstract layer and the event-avoidance constraint are distinctive.

### Cited Findings
- Eysenbach, Salakhutdinov, Levine. "Search on the Replay Buffer: Bridging Planning and Reinforcement Learning." NeurIPS 2019; arXiv:1906.05253 **[verified existence; venue from memory]** — [alphaXiv](https://www.alphaxiv.org/abs/1906.05253) (CMU, Google, UC Berkeley).
- Emmons, Jain, Laskin, Kurutach, Abbeel, Pathak. "Sparse Graphical Memory for Robust Planning." NeurIPS 2020; arXiv:2003.06417 — [arXiv](https://arxiv.org/abs/2003.06417) **[from memory - unverified]**.
- Shang, Trott, Zheng, Xiong, Socher. "Learning World Graphs to Accelerate Hierarchical Reinforcement Learning" (arXiv:1907.00664, 2019) — [arXiv](https://arxiv.org/abs/1907.00664) **[from memory - unverified; authors/venue need checking — the prompt's "Zhang et al." attribution may be wrong]**.
- Recent graph-search-over-experience works: "Test-Time Graph Search for Goal-Conditioned RL" (arXiv 2510.07257) — [alphaXiv](https://www.alphaxiv.org/abs/2510.07257); "Strict Subgoal Execution" (arXiv 2506.21039) — [alphaXiv](https://www.alphaxiv.org/abs/2506.21039); "Learning to Plan from Random Exploration" (arXiv 2609.38383, Sep 2026) — [alphaXiv](https://www.alphaxiv.org/abs/2609.38383) **[existence verified; content not read]**.
- Symbolic-side landmarks: "Revisiting Landmarks: Learning from Previous Plans to Generalize over Problem Instances" (arXiv 2508.21564) — [alphaXiv](https://www.alphaxiv.org/abs/2508.21564) **[existence only]**.

### Inferences
- SoRB-style graphs are over a *single* MDP with continuous/visual states and learned distances; the thesis' H stores exact deterministic transitions (x, a, x') so BFS gives guaranteed-executable paths, and the graph persists and grows across goals in the same environment.
- The thesis' inner search adds a **constraint unique to the hidden-symbolic setting**: the low-level path must not traverse transitions that are events other than the targeted one (since they would change c unpredictably). No graph-over-replay-buffer paper found here has such an abstract-level side-effect constraint. This resembles "frame preservation" in PaRL (penalising frame violations via intrinsic reward) — but enforced by search rather than reward.
- Verdict: **partial (methodological) overlap**; distinctive = event-avoidance constraint, two-level BFS over (x, Π), exact-transition edges, persistence across goals.

## 5. Benchmarks/frameworks with procedural generation and a symbolic layer

### Takeaway
XLand-MiniGrid is the closest benchmark: tasks are defined by goals plus *production rules* that deterministically change the environment when conditions are met, rules/goals are hidden from the agent, and task distributions are procedurally generated — very close to "environments generated from θ sharing a rule set" with event-like triggers. However, rule effects change the observable grid (x), not a separate hidden symbolic theory. IBM's parl_minigrid pairs MiniGrid with STRIPS tasks but the symbolic state is derived from x. Overlap: **partial**; no benchmark found that models a hidden STRIPS state c alongside x with truthful partial observation.

### Cited Findings
- Nikulin et al. "XLand-MiniGrid: Scalable Meta-Reinforcement Learning Environments in JAX." ### Inferences
- XLand-MiniGrid rules ≈ thesis events (condition on low-level configuration → deterministic effect), and its procedural task generation ≈ θ. But (a) rules' effects are visible in the grid, (b) the agent does not get the rule set as a planning domain — so it is a meta-RL benchmark, not a planning-with-hidden-theory benchmark. It is a strong candidate testbed if one adds a hidden symbolic layer.
- Crafter/Craftax/MineDojo/Plan4MC have implicit tech-tree "operators" (craft X requires Y) that are triggered by low-level actions at specific configurations — event-like — and procedural generation; their symbolic states (inventory, achievements) are observable, though world contents are partially observable (ego-centric view). Verdict: **partial/superficial**.
- PDDLGym: **superficial** (symbolic only).
